# Abdullah Portfolio

A stylish bilingual personal portfolio for Abdullah, featuring cybersecurity and web development content, plus a simple dashboard for managing projects.

## Features
- Premium dark luxury design
- Arabic and English language toggle
- Portfolio sections for about, skills, projects, and contact
- Admin dashboard for adding projects using localStorage
- Instagram contact link: @apood_we

## Admin Login
Default password:
- `admin123`

You can change it in the `script.js` file by editing the `DEFAULT_PASSWORD` value.

## Run locally
Open `index.html` in a browser.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Notes
This is a front-end portfolio and dashboard. The project data is stored in the browser via `localStorage`, so it persists on the same device/browser used to edit it.

## Deployment
If you want, this site can later be deployed easily to GitHub Pages or a hosting platform.
